# 📟 Calculadora em React com Tailwind

Este projeto é uma **calculadora** desenvolvida em **React/JavaScript** com **Tailwind CSS**.

## 🚀 Tecnologias utilizadas:
- React.js
- JavaScript (ES6+)
- Tailwind CSS para estilização

## 📌 Funcionalidades:
- Operações básicas: **soma, subtração, multiplicação e divisão**

## 🎯 Objetivos de aprendizado:
- Praticar o uso de **React** e *Tailwind*
